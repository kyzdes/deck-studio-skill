# Макеты слайдов

Все макеты живут в `assets/template/src/deck.html` — это каталог из 20 рабочих слайдов. Новую деку собирайте копированием нужных `<section>` оттуда, а не с нуля: разметка уже согласована с CSS и формациями.

## Система координат

- Сцена 1920×1080, движок масштабирует её под окно (letterbox). Все размеры и `left/top` в пикселях сцены.
- Поля: слева и справа 120, сверху у `.pad` — 140 (рубрика), заголовок ниже на 40.
- `.abs` + `style="left:…;top:…"` — абсолютное позиционирование относительно сцены.
- Низ: прогресс-бар на 1022 — ниже 1000 ничего не ставьте.

## Каркас слайда

```html
<section class="slide" data-fx="sphere" data-act="01 · Раздел" data-time="1:00">
  <div class="pad">
    <div class="kicker up" style="--d:.15s">Рубрика — вопрос зала</div>
    <h2 class="t t-m" data-a="words" data-d=".3">Заголовок-утверждение с <em>акцентом</em></h2>
  </div>
  … тело макета …
  <aside class="notes"><p>Что сказать. [Клик] — где нажимать.</p></aside>
</section>
```

- `data-fx` — формация частиц (`particles.md`); через `|` — своя на каждый шаг: `box|tardis`.
- `data-act` — подпись раздела в левом верхнем углу; `data-time` — план на слайд (сумма = длительность).
- Заголовок: `.t` + размер `.t-xl` 128 / `.t-l` 104 / `.t-m` 86, `data-a="words"` — появление по словам, `<em>` — акцент цветом и курсивом.
- `.up` — появление с размытием; задержка `--d`. Ставьте 1.0–1.6s для тела, чтобы оно шло после заголовка.
- `data-step="1"` — элемент появляется по клику (стрелка/пробел), шаги нумеруются с 1.
- Числа и имена — `<span data-f="поле" data-ph="N" data-suffix="%">` из `DECK_DATA`; `data-count` — досчитывание; `null` → пунктирная заглушка.

## Рецепты

- **Широкий скриншот** (много деталей): заголовок на всю ширину сверху, `figure.shot` справа `left:900px;top:410px;width:900px`, пункты слева `.shot-notes` с `style="top:450px;width:680px"`.
- **Три колонки** вместо четырёх: `.tools` вместо `.tools4`, формация `icons@a,b,c` сама разложит фигуры.
- **Длинный заголовок** не помещается в 2–3 строки: уменьшите `.t-l` → `.t-m` или задайте `style="font-size:72px"`; переносы проверяйте на скриншоте.
- **Сетка оценок**: `data-groups="10:27,9:5,8:1"` — первая группа сплошным акцентом (`g0`), вторая контуром (`g1`), третья и дальше тихим контуром (`g2`); в легенде те же классы `<i class="g0|g1|g2">`.
- **Подпись мелким под цифрами** — `.period` (моно, 20px). Не ставьте на слайд оговорок вроде «по нашей оценке», если автор о них не просил.
- **Тайминг**: добавили слайд — снимите по 15 секунд с соседних, сумма `data-time` должна сойтись (проверяет `check_deck.py`).
