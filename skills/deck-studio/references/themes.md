# Темы: токены, палитры, шрифты

Всё оформление деки — CSS-переменные в `:root` из `engine.css`. Тема меняется блоком `<style>` в `deck.html` (он уже стоит в шаблоне после подключения `engine.css`), движок не трогается. Частицы и графики берут цвета из тех же токенов при загрузке страницы.

## Токены

| Токен | Что красит | По умолчанию |
|---|---|---|
| `--bg` | Фон страницы | `#07080b` |
| `--ink` | Заголовки, основной текст, частицы «0» | `#f1eee8` |
| `--muted` | Рубрики, подписи, частицы «2» | `#9b9ca4` |
| `--faint` | Самый тихий текст | `#4a4c55` |
| `--line` | Линии, рамки карточек | `rgba(241,238,232,.14)` |
| `--line-2` | Пунктир артборда | `rgba(241,238,232,.2)` |
| `--accent` | `<em>` в заголовках, метки, ссылки, частицы «1» и «3» | `#e8875f` |
| `--accent-soft` / `--accent-tint` / `--accent-line` | Заливки голосов, CTA, подчёркивания ссылок | акцент с прозрачностью .18 / .08 / .4 |
| `--on-accent` | Текст на сплошном акценте | `#1a0f0a` |
| `--body` / `--body-hi` | Вторичный текст в карточках и списках | `#c9c7c1` / `#d6d4cf` |
| `--caption` | Подписи под цитатами | `#6f717b` |
| `--panel` / `--panel-solid` | Полупрозрачные карточки / окна (терминал, скриншот, справка) | `rgba(10,11,15,.62)` / `.94` |
| `--dim` / `--off` | Кнопки окна, незажжённые точки | `#2c2e36` / `#3b3e48` |
| `--glow-1` / `--glow-2` | Два мягких пятна света на фоне | акцент .09 / синий .05 |
| `--shadow` | Тень окон | `rgba(0,0,0,.55)` |
| `--serif` | Заголовки, цитаты, названия | Cormorant Garamond |
| `--sans` | Текст | Inter Tight |
| `--mono` | Рубрики, метки, терминал, ссылки | JetBrains Mono |

Меняя `--accent`, перекрасьте и производные (`--accent-soft`, `--accent-tint`, `--accent-line`, `--glow-1`): они заданы отдельными числами, а не формулой, чтобы работать в любом браузере.

## Три направления из мудборда

Мудборд (`moodboard.md`) предлагает три направления; автор часто выбирает смесь. Тема по умолчанию — смесь A и C: тёмный космос + антиква с тёплым акцентом. Ниже — готовые блоки для `<style>` в `deck.html`.

### A — «Космос» (холодный, технологичный)

```css
:root {
  --bg: #050507; --ink: #f2f4f8; --muted: #8e98a8; --faint: #4a5160;
  --line: rgba(242,244,248,.13); --line-2: rgba(242,244,248,.2);
  --accent: #9ec5ff; --accent-soft: rgba(158,197,255,.18); --accent-tint: rgba(158,197,255,.08); --accent-line: rgba(158,197,255,.4);
  --on-accent: #07101e; --body: #c4c9d3; --body-hi: #d5d9e1;
  --glow-1: rgba(107,76,255,.10); --glow-2: rgba(158,197,255,.06);
  --serif: 'Inter Tight', system-ui, sans-serif;   /* заголовки гротеском */
}
.t { font-weight: 300; letter-spacing: -.035em; }
.t em { font-style: normal; }
```

### B — «Тёплый объект» (плотный, плакатный)

Нужен шрифт Unbounded: `make_fonts.py <дека> "Unbounded:wght@400;900" "Inter Tight:wght@300;400;500" "JetBrains Mono:wght@400;500"`.

```css
:root {
  --bg: #120b07; --ink: #f3e6d3; --muted: #b48a66; --faint: #5e4632;
  --line: rgba(243,230,211,.14); --line-2: rgba(243,230,211,.22);
  --accent: #ff8a2a; --accent-soft: rgba(255,138,42,.18); --accent-tint: rgba(255,138,42,.08); --accent-line: rgba(255,138,42,.45);
  --on-accent: #1d0a03; --body: #dccab2; --body-hi: #eadbc5;
  --panel: rgba(29,14,6,.6); --panel-solid: rgba(24,12,6,.95); --dim: #3a2416; --off: #4a3020;
  --glow-1: rgba(201,80,15,.16); --glow-2: rgba(255,138,42,.05);
  --serif: 'Unbounded', system-ui, sans-serif;
}
.t { font-weight: 900; letter-spacing: -.02em; text-transform: uppercase; line-height: .98; }
.t-xl { font-size: 104px; } .t-l { font-size: 86px; } .t-m { font-size: 70px; }
```

### C — «Редакция» (светлая бумага, антиква)

```css
:root {
  --bg: #f4f1ea; --ink: #121212; --muted: #8a857b; --faint: #b5afa4;
  --line: rgba(18,18,18,.14); --line-2: rgba(18,18,18,.24);
  --accent: #d97757; --accent-soft: rgba(217,119,87,.16); --accent-tint: rgba(217,119,87,.08); --accent-line: rgba(217,119,87,.45);
  --on-accent: #ffffff; --body: #3a3833; --body-hi: #2a2825; --caption: #8a857b;
  --panel: rgba(255,255,255,.55); --panel-solid: rgba(250,248,243,.96); --dim: #d9d4ca; --off: #c9c3b8;
  --glow-1: rgba(217,119,87,.10); --glow-2: rgba(0,0,0,0); --shadow: rgba(40,30,20,.18);
}
```

На светлом фоне частицы читаются как тушь на бумаге — это и есть характер направления C. Проверьте скриншотом слайды с плотным текстом поверх `dust`: если пыль мешает, возьмите `horizon` или уберите формацию с этого слайда (`data-fx="horizon"`).

## Шрифты

`src/fonts/fonts.css` — шрифты в base64 (кириллица + латиница), чтобы дека открывалась без интернета. Заменить набор:

```
python3 <skill>/scripts/make_fonts.py ./presentation "Cormorant Garamond:ital,wght@0,500;0,600;1,500" "Inter Tight:wght@300;400;500" "JetBrains Mono:wght@400;500"
```

Семейства и оси — как в адресе `fonts.googleapis.com/css2`. После замены поправьте `--serif / --sans / --mono` и пересоберите (`python3 src/build.py`).

Что проверено на сцене:
- Антиква в заголовках требует `font-variant-numeric: lining-nums` (уже в движке), иначе старостильные цифры «пляшут».
- Заголовок не меньше 70 px, текст в карточках не меньше 25 px: при шаринге экрана видеокодек съедает мелкое и тонкое.
- Вес 200–300 для гротеска в заголовках хорош только на тёмном фоне и от 100 px.
- Для своей темы держите контраст `--body` к `--bg` не ниже 7:1: вторичный текст читают с другого конца переговорки.
