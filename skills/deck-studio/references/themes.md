# Темы: светлая и тёмная, акценты, токены, шрифты

Оформление деки — CSS-переменные из `engine.css`. Тема и акцент задаются двумя атрибутами `<html>` в `deck.html`, движок не трогается:

```html
<html lang="ru" data-theme="light" data-accent="blue">
```

Новую деку сразу в нужной теме разворачивает `new_deck.py --theme light --accent blue`; свой цвет бренда — `--accent "#12a4b8"`. Проверка `check_deck.py` печатает тему и акцент и ругается на неизвестные названия.

## Светлая или тёмная

| Тема | Когда брать |
|---|---|
| `dark` (по умолчанию) | Шаринг экрана, тёмный зал, проектор с хорошим контрастом. Частицы светятся, это самый «вау»-режим |
| `light` | Светлая переговорка, слабый проектор, деку будут листать сами и пересылать. Тёплая бумага, тушь, частицы как штрихи пером |

Не уверены, какой будет зал, — нажмите **T** прямо на месте: тема переключится вместе с частицами и графиками до перезагрузки страницы. Постоянный выбор живёт в `data-theme`.

## Акценты

Один цвет акцента красит `<em>` в заголовках, метки, ссылки, голоса, CTA и частицы-«звёзды»; все оттенки (заливки, подчёркивания, свечение) считаются из него через `color-mix`. Для светлой темы у каждого акцента свой, более глубокий оттенок — так мелкие подписи держат контраст на бумаге (у всех не ниже 4,4 : 1).

| `data-accent` | Тёмная | Светлая | Характер |
|---|---|---|---|
| `terracotta` (по умолчанию) | `#e8875f` | `#ad4f2c` | Тёплый, человеческий, редакционный |
| `blue` | `#7fb2ff` | `#2f63d1` | Технологии, данные, спокойная уверенность |
| `violet` | `#ab90ff` | `#6b46d6` | ИИ, исследования, «будущее» |
| `green` | `#5fd09c` | `#1d7f54` | Рост, деньги, устойчивость |
| `amber` | `#f3b94d` | `#9c6200` | Энергия, запуск, призыв к действию |
| `rose` | `#ff7d9d` | `#c4345c` | Продукт для людей, бренд, смелость |
| `mono` | `#ffffff` | `#000000` | Строго: акцент держится курсивом, без цвета |

**A** на сцене перебирает акценты по кругу — удобно показать автору варианты за десять секунд. Со своим цветом бренда A его не трогает и говорит об этом.

Свой цвет (бренд компании): `new_deck.py --accent "#12a4b8"` сам подберёт оттенки для обеих тем с контрастом не ниже 4,5 : 1 и запишет их в `<style>`. Вручную — так же, для каждой темы свой оттенок:

```css
:root { --accent: #12a4b8; }
[data-theme="light"] { --accent: #0b7886; }   /* темнее, чтобы держать контраст на бумаге */
```

Проверка контраста: акцент к фону не ниже 4,5 : 1 для мелких подписей (в тёмной теме это обычно светлый тон, в светлой — глубокий).

## Токены

| Токен | Что красит |
|---|---|
| `--bg` | Фон страницы |
| `--ink` | Заголовки, основной текст, частицы «0» |
| `--muted` | Рубрики, подписи, частицы «2» |
| `--faint` | Самый тихий текст |
| `--line` / `--line-2` | Линии и рамки / пунктир артборда |
| `--accent` | Акцент; частицы «1» и «3» |
| `--accent-soft` / `--accent-tint` / `--accent-line` / `--glow-1` | Производные от акцента: заливки голосов, CTA, подчёркивания, свечение фона |
| `--on-accent` | Текст на сплошном акценте |
| `--body` / `--body-hi` | Вторичный текст в карточках и списках |
| `--caption` | Подписи под цитатами |
| `--panel` / `--panel-solid` | Карточки / окна (терминал, скриншот, справка) |
| `--dim` / `--off` | Кнопки окна, незажжённые точки |
| `--glow-2` | Второе пятно света (синее в тёмной теме, нет в светлой) |
| `--shadow` | Тень окон |
| `--serif` / `--sans` / `--mono` | Заголовки и цитаты / текст / рубрики, метки, терминал |

Значения обеих тем — в начале `engine.css`. Переопределять их стоит в `<style>` деки, а не в движке: так деку можно обновить свежим движком.

## Направления из мудборда

Мудборд (`moodboard.md`) предлагает три направления. «Редакция» (C) теперь встроена — это `data-theme="light"`. Тема по умолчанию — смесь A и C: тёмный космос и антиква с тёплым акцентом. Для A и B ниже блоки для `<style>` в `deck.html`; оттенки акцента досчитаются сами.

### A — «Космос» (холодный, технологичный)

```css
:root {
  --bg: #050507; --ink: #f2f4f8; --muted: #8e98a8; --faint: #4a5160;
  --line: rgba(242,244,248,.13); --line-2: rgba(242,244,248,.2);
  --accent: #9ec5ff; --body: #c4c9d3; --body-hi: #d5d9e1; --glow-2: rgba(107,76,255,.08);
  --serif: 'Inter Tight', system-ui, sans-serif;   /* заголовки гротеском */
}
.t { font-weight: 300; letter-spacing: -.035em; }
.t em { font-style: normal; }
```

### B — «Тёплый объект» (плотный, плакатный)

Нужен шрифт Unbounded: `make_fonts.py <дека> "Unbounded:wght@400;900" "Inter Tight:wght@300;400;500" "JetBrains Mono:wght@400;500"`.

```css
:root {
  --bg: #120b07; --ink: #f3e6d3; --muted: #b48a66; --faint: #5e4632;
  --line: rgba(243,230,211,.14); --line-2: rgba(243,230,211,.22);
  --accent: #ff8a2a; --body: #dccab2; --body-hi: #eadbc5;
  --panel: rgba(29,14,6,.6); --panel-solid: rgba(24,12,6,.95); --dim: #3a2416; --off: #4a3020;
  --glow-2: rgba(201,80,15,.12);
  --serif: 'Unbounded', system-ui, sans-serif;
}
.t { font-weight: 900; letter-spacing: -.02em; text-transform: uppercase; line-height: .98; }
.t-xl { font-size: 104px; } .t-l { font-size: 86px; } .t-m { font-size: 70px; }
```

### C — «Редакция»

Встроена: `data-theme="light"`. На светлом фоне частицы читаются как тушь на бумаге. Проверьте скриншотом слайды с плотным текстом поверх `dust`: если пыль мешает, возьмите `horizon`.

## Шрифты

`src/fonts/fonts.css` — шрифты в base64 (кириллица + латиница), чтобы дека открывалась без интернета. Заменить набор:

```
python3 <skill>/scripts/make_fonts.py ./presentation "Cormorant Garamond:ital,wght@0,500;0,600;1,500" "Inter Tight:wght@300;400;500" "JetBrains Mono:wght@400;500"
```

Семейства и оси — как в адресе `fonts.googleapis.com/css2`. После замены поправьте `--serif / --sans / --mono` и пересоберите (`python3 src/build.py`).

Что проверено на сцене:
- Антиква в заголовках требует `font-variant-numeric: lining-nums` (уже в движке), иначе старостильные цифры «пляшут».
- Заголовок не меньше 70 px, текст в карточках не меньше 25 px: при шаринге экрана видеокодек съедает мелкое и тонкое.
- Вес 200–300 для гротеска в заголовках хорош только на тёмном фоне и от 100 px.
- `color-mix` нужен браузер 2023 года и новее (Chrome 111, Safari 16.2, Firefox 113); на старом проекторном ноутбуке откройте деку заранее.
- Для своей темы держите контраст `--body` к `--bg` не ниже 7:1: вторичный текст читают с другого конца переговорки.

## Стиль «Сетка» (`--style grid`)

Второй стиль деки, без поля частиц. Появился из реальной вводной к стратсессии: автор попросил «корпоративно, аккуратно, футуристично и новенько» вместо космоса, а после сборки сказал, что претензий к дизайну больше нет. Референсы Mobbin: Mistral AI (видимая сетка, перекрестия, пиксельная мозаика), Vercel (тонкие крупные цифры с моно-подписями), Spade (ячейки с метками по углам), Raw Materials (подпись слева, большое утверждение справа, номера в овалах).

```
python3 <skill>/scripts/new_deck.py ./presentation --style grid --title "Название" --accent violet
```

- **Всегда светлая:** бумага `#F5F5F2`, сетка 160×120 на каждом слайде, линия под шапкой. `--theme` не действует.
- **Два цвета:** `--accent` (любой из семи или свой `#hex`) — данные, акцентные слова, ячейка `.c.v`; жёлтый `--y` — маркер `<mark>`, одна главная вещь на слайде. Оттенки мозаики и столбиков выводятся из акцента.
- **Раскладка:** подпись раздела `.side` в левой колонке («[ 01 ] Подпись»), заголовок с 640 px, контент — от 160 до 1760 px по сетке.
- **Движение вместо частиц:** мозаика `.mosaic` (с `.auto` гаснет сама до ячейки `data-hit`, без — по клику на `.go-focus`), стрелки `.vecs` (по клику `.go-vec` разворачиваются в одну сторону, полоса суммы растёт — самый сильный момент в живом показе), бейдж `.badge.old/.new` (смена роли по клику), колонки `.years` с последней по клику, проявление заголовка из размытия `.pull`.
- **16 макетов** в `assets/styles/grid/deck.html`: обложка с мозаикой, утверждение + три ячейки, колонки цифр, цитаты строками, три цифры, мозаика по клику, векторы, четыре ячейки, определение + проверки, смена роли, диалог, нумерованные строки, вопросы с пропуском, мини-слайды формата, чек-лист + вопрос, финал.
- **Тексты:** стиль строгий, поэтому пафос в нём слышен сильнее. Заголовки простыми словами, без лозунгов и «не X, а Y»; одна цифра — одна подпись (две цифры через «/» зал читает как дробь).
