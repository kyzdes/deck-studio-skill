# Частицы: формации, фигуры, свои метафоры

Поле из N = 1800 частиц на canvas под сценой. У каждого слайда своя **формация** (`data-fx`); при смене слайда частицы перетекают в новую форму с лёгким завихрением и успокаиваются за 1,4–3 с. Переход между формациями и продаёт деку: две соседние одинаковые формации — это стоп-кадр, а не анимация.

Строгой корпоративной теме поле может быть не нужно: `window.DECK_CONFIG = { …, particles: false }` выключает его целиком — canvas скрыт, кадры не считаются, `data-fx` можно не писать, `check_deck.py` формации пропускает.

Цвета частиц берутся из CSS-токенов: коды фигур `0` — `--ink`, `1` и `3` — `--accent` (1 — крупная «звезда», 3 — обычная), `2` — `--muted`.

## Как задать

```html
<section class="slide" data-fx="sphere">                     <!-- по умолчанию -->
<section class="slide" data-fx="sphere@960,540,260">         <!-- свои аргументы через запятую -->
<section class="slide" data-fx="box|tardis">                 <!-- шаг 0 — box, после первого клика — tardis -->
<section class="slide" data-fx="icons@540,gear,bulb">        <!-- по фигуре над каждой колонкой -->
<section class="slide" data-fx="shape@rocket,1420,600,1.9">  <!-- одна фигура в точке -->
```

Числа в аргументах становятся числами, остальное — именами. Неизвестная формация → `dust` и предупреждение в консоли (`check_deck.py` ловит заранее).

## Фигуры для `icons@` и `shape@`

Встроенные: `planet` (сфера с кольцом), `artboard` (макет окна), `laptop` (ноутбук с промптом), `mlnet` (нейросеть), `gear` (шестерёнка, вращается в плоскости), `bulb` (лампочка с лучами), `tardis`.

`icons@` раскладывает фигуры по ширине 1680 px от левого поля 120: зазор 48 / 40 / 32 px и масштаб ×1,25 / ×1 / ×0,9 для 2 / 3 / 4 колонок. Бюджет частиц на фигуру — `(N − 80) / k`, остаток уходит в пыль. Первый числовой аргумент — высота центров (`icons@540,…`); подгоняйте её под верх колонок.

Правило из реальной правки: **у каждого объекта своя фигура.** Три одинаковые сферы над тремя инструментами читаются как заглушка.

## Своя фигура: `window.DECK_SHAPES`

Фигура — массив точек `[x, y, z, цвет]` вокруг (0, 0, 0), в «единицах иконки» (встроенные — примерно ±100). Движок вращает её, даёт перспективу и затемняет дальнюю сторону.

```html
<script>
window.DECK_SHAPES = {
  rocket: {
    build: h => {
      const body  = h.resample([[0,-92],[18,-62],[24,-20],[24,40],[42,64],[24,58],[14,70],[-14,70],[-24,58],[-42,64],[-24,40],[-24,-20],[-18,-62]], 260, 0, true);
      const port  = h.resample(h.arc(0, -22, 11, 0, Math.PI * 2, 30), 40, 3, true);
      const flame = h.resample([[-12,76],[-5,92],[0,112],[5,92],[12,76]], 50, 3);
      return [...body, ...port, ...flame];
    },
    opt: { rot: .35, osc: .5, tilt: .1 }
  }
};
</script>
```

Скрипт ставится **до** `engine.js`. После этого `rocket` доступна и в `shape@rocket,…`, и в `icons@…,rocket`.

Хелперы (`h`):

| Хелпер | Что делает |
|---|---|
| `h.resample(poly, count, цвет, closed)` | Ломаную `[[x,y],…]` → `count` точек **равномерно по длине**. Главный инструмент: контур получается сплошным |
| `h.arc(cx, cy, r, a0, a1, n)` | Дуга как ломаная из `n` отрезков (для `resample`) |
| `h.seg(out, a, b, count, цвет)` | Отрезок между 3D-точками, дописывает в `out` |
| `h.loop(out, [p1, p2, …], count, цвет)` | Замкнутый многоугольник из 3D-точек (рёбра коробки, рамки) |

Опции фигуры (`opt`):

| Опция | По умолчанию | Смысл |
|---|---|---|
| `rot` | .3 | Скорость вращения (рад/с) или амплитуда при `osc` |
| `osc` | 0 | Частота покачивания; 0 — полный оборот. Плоским фигурам ставьте `osc`, чтобы не показывать ребро |
| `axis` | — | `'z'` — вращение в плоскости экрана (шестерёнка) |
| `tilt` | .3 | Наклон к зрителю |
| `scale` | 1 | Множитель размера |
| `R` | 100 | Радиус для расчёта глубины; для крупных фигур ставьте больше размера фигуры |
| `minA`, `depthPow` | .35, 1 | Яркость дальней стороны и крутизна затемнения (у TARDIS .06 и 1,4 — объём читается лучше) |
| `alpha` | .95 | Общая яркость |

### Как рисовать, чтобы не было «кринжово»

- Контур — одной замкнутой ломаной через `resample`, а не набором отрезков с разной плотностью: неравномерные точки выглядят как «скобки».
- 250–450 точек на фигуру при `icons@` на 2–3 колонки, до 1400 — для `shape@` на весь слайд. Больше `N − 200` движок не возьмёт.
- Акцент (`3`) — на одну деталь: иллюминатор, нить лампочки, огонь на крыше. Вся фигура акцентом — это пятно.
- Объём (будка, коробка) — рёбрами через `seg`/`loop` по трём осям; плоская фигура — с `osc`, чтобы не крутилась ребром к залу.
- Проверяйте фигуру скриншотом в двух фазах вращения: ракурс с ребра часто ломает узнаваемость.

## Производительность и доступность

- Всего 1800 частиц на любой слайд: формация с несколькими слоями делит их между слоями (`sphere` 1500 + пыль 300).
- `prefers-reduced-motion` замораживает вращение и переходы: дека остаётся читаемой.
- Частицы далеко от цели после успокоения телепортируются: ни одна не «висит» в углу.
