# deck-studio

Презентации одним HTML-файлом, которые выглядят как сайт студии: сцена 1920×1080, под ней поле из 1800 частиц, которое на каждом слайде складывается в новую фигуру — сферу, кольцо, рамку, будку TARDIS, ракету или любую свою. Заголовки проявляются по словам, цифры досчитываются, шаги открываются по клику, у спикера своё окно с таймером и заметками. Шрифты и картинки вшиты: файл открывается без интернета и показывается шарингом экрана. Тема светлая или тёмная, семь готовых акцентов или цвет бренда; на сцене T переключает тему, A — акцент.

Метод собран из реальной сборки: доклад на 20 минут перед стратсессией, 20 слайдов, около 30 итераций с автором за один день. Каждая правка автора стала правилом скилла.

Чем отличается от `deck-copy`: тот пишет текст деки по жанру, этот собирает саму деку — от мудборда до файла на сцене — и зовёт `deck-copy` на этапе текстов.

## Что внутри

| Файл | Что там |
|---|---|
| `SKILL.md` | вход: семь шагов, устройство деки, десять правил, клавиши, чек-лист сдачи |
| `references/process.md` | путь целиком: этапы, контрольные точки, таблица «что автор правил и почему это правила» |
| `references/moodboard.md` | запросы к Mobbin, скачивание референсов, сборка мудборда с живым движением |
| `references/copy-rules.md` | сюжетная дуга доклада, правила заголовков, вычитка агентом, сообщение в чат |
| `references/layouts.md` | каталог 20 макетов: когда какой брать, координаты сцены, рецепты |
| `references/particles.md` | формации частиц, встроенные фигуры, свои фигуры через `DECK_SHAPES` |
| `references/themes.md` | светлая и тёмная темы, семь акцентов, цвет бренда, токены, шрифты |
| `references/gotchas.md` | проверка в браузере, вёрстка, окно заметок, сцена |
| `assets/template/src/` | движок (`engine.js`, `engine.css`), каталог-дека на 20 слайдов, сборщик, шрифты |
| `assets/moodboard/` | шаблон мудборда на три направления |
| `scripts/new_deck.py` | новая дека из шаблона: название, длительность, `copy.md` |
| `scripts/check_deck.py` | проверка: тайминг, пустые поля, неизвестные формации, открытые вопросы |
| `scripts/make_fonts.py` | шрифты Google Fonts в base64 (кириллица + латиница) |
| `scripts/build_moodboard.py` | самодостаточный мудборд из шаблона и папки референсов |

## Порядок работы

1. Бриф: тема, зал, что сделают после, как показывают, длительность.
2. Мудборд по Mobbin, автор выбирает направление.
3. Сюжет и тексты в `copy.md`, вычитка агентом `deck-copywriter`.
4. `new_deck.py` → правка `src/deck.html` → `src/build.py` → `index.html`.
5. `check_deck.py` и скриншоты каждого слайда.
6. Итерации по размеченным скриншотам автора.
7. Сдача: клавиши, сообщение со ссылками для чата.

Быстрый старт без агента:

```
python3 skills/deck-studio/scripts/new_deck.py ~/Desktop/my-talk --title "Мой доклад" --minutes 15 --theme light --accent blue
python3 ~/Desktop/my-talk/src/build.py
open ~/Desktop/my-talk/index.html
```

## Установка

Плагин живёт в публичном маркетплейсе [kyzdes/claude-skills](https://github.com/kyzdes/claude-skills). Если вы его ещё не подключали, начните с первой команды.

Claude Code (команды вводятся в сессии):

```
/plugin marketplace add kyzdes/claude-skills
/plugin install deck-studio@claude-skills
```

Codex:

```
codex plugin marketplace add https://github.com/kyzdes/claude-skills.git
codex plugin add deck-studio@claude-skills
```

Маркетплейс уже подключён — обновите его и поставьте плагин:

```
claude plugin marketplace update claude-skills
claude plugin install deck-studio@claude-skills
```

```
codex plugin marketplace upgrade
codex plugin add deck-studio@claude-skills
```

После установки откройте новую сессию и напишите, например: «Сделай крутую презентацию на HTML про …». Плагин обновляется сам при старте сессии, не чаще раза в 4 часа; отключить — переменная окружения `KKZ_NO_AUTOUPDATE=1`.

## Границы

Файлы `.pptx`, Keynote и Google Slides — скилл `pptx`. Только тексты существующей деки — плагин `deck-copy`. Сайты и лендинги — не сюда: дека живёт на фиксированной сцене 16:9 и листается клавишами.
